# Project Description
This is a learning project, to add skills like LangChain, LangGraph, etc.

## Cloud model
- i am using Google Gemini as LLM provider, in Free Tier.
* Mostly `model="gemini-2.5-flash"`
Command to add Google Gemini in LangChain: ``uv add langchain-google-genai``

## How to run Local model.
I am using ollama, to run a model. A light weight model as there are hardware limitation:
- CPU: i5 10th Gen
- RAM (DDR4): 16GB
- GPU: AMD Radeon 610 Series
- Dedicated GPU memory: 2GB
